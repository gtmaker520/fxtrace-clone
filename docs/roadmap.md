## P2 算法增强（研发价值最高）

### ① 谐波阶次分解 —— 解决"THD 只是一个标量"

按 2f/3f/4f… 分解谐波幅度谱：

- **偶次谐波为主**（2f 强）→ 非对称削波 → 单管/二极管不对称电路（TS、Fender 风格）
- **奇次谐波为主**（3f 强）→ 对称削波 → 运放/对管对称电路（RAT、Mesa 风格）

实现成本极低（THD 分析已采集峰值谱，只需按频点分组），直接把"软/硬削波"二分类升级为"削波拓扑"分类，接入 `selectDriveEffect`。

### ② 多电平扫频 —— 解决"drive 真实反解"（硬削波路径目前 driveDb=0 放弃）

用 3–5 档输入电平重复扫频：

- 不同电平下频响/THD 的**变化率**即压缩特性 → 反解 drive/压缩参数，替代硬编码查表
- 同时可分离"设备增益"与"信号电平"（现在 I/O 路径无法直接比较输入输出增益）

### ③ 匹配度分母改相对误差

36dB 硬编码 → 以信号实际动态范围归一化，使匹配度在不同设备间可比。

### ④ 动态分析改进

dB 范围→压缩比的线性映射，改为基于输入-输出电平曲线的分段拟合。

## P3 "真克隆"路线（长期）

### Wiener-Hammerstein 模型

拟合非线性传递函数（线性动态 → 静态非线性 → 线性动态），对标 ToneX/NAM 的简化版：

- 线性部分：现有扫频频响已可估计
- 非线性部分：多电平扫频（P2 ②）提供不同工作点的增益数据
- 产物从"风格归类"升级为"波形级建模"——失真类相似度从 ~50% 有望进入 80%+
